# 🧮 BMI Calculator

A simple and beginner-friendly BMI (Body Mass Index) Calculator built using Python.

This program takes the user's name, weight, and height as input, calculates their BMI, and displays the corresponding BMI category.

## ✨ Features

- 👤 Takes the user's name
- ⚖️ Takes weight in kilograms
- 📏 Takes height in centimeters
- 🧮 Calculates BMI
- 📊 Displays the BMI value
- 📋 Displays the BMI category
- 👋 Shows a personalized thank-you message

## 🛠️ Technologies Used

- Python 3

## 🚀 How to Run

### 1. Clone the repository

git clone https://github.com/YOUR-USERNAME/BMI-Calculator.git

### 2. Open the project folder

cd BMI-Calculator

### 3. Run the program

python bmi_calculator.py
